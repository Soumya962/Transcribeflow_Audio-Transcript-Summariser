 TranscribeFlow: Audio Transcript Summarizer
 Project Overview

TranscribeFlow is a web-based application that converts audio files into text and generates a concise summary using Artificial Intelligence. It helps students, professionals, and researchers quickly extract key insights from long audio content like lectures, meetings, and podcasts.

 Problem Statement

Reviewing long audio recordings is time-consuming. Manually transcribing and summarizing audio involves multiple steps and reduces productivity.

Solution:
TranscribeFlow automates this process by:

Converting audio to text (Transcription)
Generating a summary (Summarization)

Objectives
Convert audio files into accurate text
Generate concise summaries of transcripts
Provide a simple and user-friendly interface
Support common audio formats (MP3, WAV)

Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Python (Flask)
AI Models:
Speech Recognition: Wav2Vec2 / Whisper
Summarization: T5 / BART
Libraries: Hugging Face Transformers
